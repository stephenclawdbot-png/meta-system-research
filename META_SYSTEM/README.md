# META-SYSTEM: Autonomous Project Orchestrator
## The System That Manages Systems

### Purpose
Continuously ideate, research, prototype, and document revolutionary technologies via automated project lifecycle management.

### Core Loop
1. **Ideate** → Generate breakthrough concepts
2. **Validate** → Feasibility analysis via expert agents
3. **Document** → GitHub repo + public documentation
4. **Prototype** → BOM, build plans, component sourcing
5. **Iterate** → Continuous improvement cycles
6. **Archive** → Completed projects, lessons learned

### Active Projects Registry
Tracked in `PROJECT_REGISTRY.json` — auto-updates every heartbeat.

### Project Lifecycle States
- `ideating` → Concept generation
- `validating` → Feasibility research
- `documenting` → Repo creation, README writing
- `prototyping` → Hardware/software build
- `testing` → Validation and iteration
- `complete` → Archived with final report
- `abandoned` → Fatal flaw identified, documented why

### Heartbeat Structure
Every 5 minutes:
- Check all active projects
- Advance each project one step
- Generate new project ideas if slots available
- Document progress to GitHub
- Post updates to X (@wino65)

### Project Slots
Max 3 concurrent active projects to maintain focus.

1. **Slot A:** [Current] AETHER Display — Cycle 2
2. **Slot B:** [Current] SILENT Interface — Cycle 0 complete
3. **Slot C:** [Available] Next breakthrough concept

### Success Criteria
Project graduates when:
- BOM finalized and sourced
- Working prototype demonstrated
- Documentation complete
- Or: Fatal flaw proven, documented why
