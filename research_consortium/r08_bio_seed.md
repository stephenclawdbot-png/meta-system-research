# R08: Bioengineer - Cycle 0

## Biological Display Systems

### Engineered Bioluminescence

**Concept:** Genetically modified organisms as living pixels

**Candidates:**
- *E. coli* with firefly luciferase
- Yeast with bacterial lux operon
- Algae with dinoflagellate luciferase

**Challenges:**
- Continuous light requires ATP (cellular energy)
- Lifespan: Hours to days
- Containment: Must prevent escape

### Synthetic Biology Display

**"Living Canvas" Approach:**
- Bioluminescent bacteria in hydrogel matrix
- Nutrient supply via microfluidic channels
- Color mixing via multiple strains
- Pattern writing via spatial gene expression

**Advantages:**
- Self-replicating (scalable)
- Self-healing (maintains pattern)
- Energy from nutrients, not electricity

**Disadvantages:**
- Slow response (minutes)
- Limited lifespan
- Biocontainment requirements

### Alternative: Biomimetic Materials

**Butterfly Wing Scales:**
- Structural color (no pigment)
- Mechanical actuation changes color
- Could be MEMS-replicated

### Hybrid Approach

**Living Smart Dust:**
- Single-celled organisms in microcapsules
- Light output controlled by optogenetics
- Wireless control via light pulses

### Ethical Considerations
- Using living systems for displays
- GMO containment
- End-of-life degradation

### Breakthrough
Bioluminescent yeast that photosynthesizes and self-regenerates in ambient light
